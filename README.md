# Monopoly F1 RU — MVP

Русскоязычный справочник для немецкой версии настольной игры Monopoly Formula 1.

## Что есть в MVP

- Next.js + React + TypeScript
- mobile-first интерфейс
- данные отдельно от компонентов (`data/catalog.json`)
- поиск по немецкому и русскому названию/тексту и ключевым словам
- fuzzy-поиск с допуском простых опечаток через Fuse.js
- фильтрация по категориям
- карточки с немецким оригиналом, переводом и блоком «Что делать»
- отдельная ссылка на каждую карточку: `/item/<id>`
- отдельная страница всех правил: `/rules`
- навигация обратно к поиску
- пустое состояние при отсутствии результатов
- без базы данных

## Запуск на Windows

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd`:

```powershell
npm.cmd install
npm.cmd run dev
```

Затем откройте:

```text
http://localhost:3000
```

## Проверка production build

```powershell
npm.cmd run build
npm.cmd start
```

## Основные файлы

- `app/page.tsx` — главная
- `components/SearchApp.tsx` — поиск и фильтры
- `components/ItemCard.tsx` — отображение карточки
- `app/item/[id]/page.tsx` — отдельная карточка по ссылке
- `app/rules/page.tsx` — полный раздел правил
- `data/catalog.json` — каталог данных
- `lib/catalog.ts` — доступ к данным

## MVP v3 — доработки

- Для категории Fahrer используется отдельная иконка гоночного шлема.
- В списке карточек сначала показывается короткое действие; немецкий оригинал и полный перевод раскрываются по кнопке «Показать полный текст».
- Добавлено ручное переключение светлой/тёмной темы с сохранением выбора в `localStorage`. При первом открытии учитывается системная тема устройства, включая iPhone.
- На главной отображается до 24 карточек, поэтому любая отдельная категория показывается целиком.
